CRIL Pythia infrastructure runbook

1. Connect:
   ssh clustercril
   ssh nodec000
   cd "$HOME/PPO_Learning_to_rank_arr"

2. Prepare and audit the fixed Pythia snapshot and the 216/54 QID split:
   bash cluster/cril/prepare_pythia.sh

3. Inspect the infrastructure preflight without creating a job:
   bash cluster/cril/submit_pythia_preflight.sh --dry-run

4. Submit the infrastructure-only H100 preflight:
   bash cluster/cril/submit_pythia_preflight.sh --submit

The preflight loads EleutherAI/pythia-70m fully offline and checks forward and
backward passes through one shared backbone and five temporary scalar heads for
ListNet, ListMLE, and MSE. It performs no scientific training and creates no
experiment checkpoint.

Do not use submit_uncertainty.sh: its current matrices are the separate
DeBERTa/Mistral controlled-adaptation protocol.

5. Validate and submit the six short Pythia Tier-2 pilots:
   bash cluster/cril/submit_tier2_pilots.sh --dry-run
   bash cluster/cril/submit_tier2_pilots.sh --submit

The array covers an independent RankingRewardModel member and a complete
shared-backbone/five-head model under ListNet, ListMLE, and MSE. Each cell uses
eight training groups, four held-out groups, and one epoch. These are execution
checks, not paper results.

6. Inspect all six pilot manifests and logs. Only then validate the full matrix:
   bash cluster/cril/submit_tier2_matrix.sh --dry-run

Do not call the full launcher with --submit before this review. The full QID
matrix contains 90 independent-member jobs and 63 shared-ablation jobs. Its
independent combine array is dependency-gated and starts only after every
independent member has completed.

7. Run the fixed-count feature-mask ablation after the original 80%-retention
   feature arms. It retains k in {20, 100, 180, 260, 340} dimensions per head for both
   `features` and `bootstrap_features`, all three objectives and all three seeds:
   bash cluster/cril/submit_tier2_feature_sweep.sh --dry-run
   bash cluster/cril/submit_tier2_feature_sweep.sh --pilot

Inspect the pilot manifest and logs, then submit the full 90-cell array:
   bash cluster/cril/submit_tier2_feature_sweep.sh --submit

After all 90 array tasks complete, run the strict aggregation. It refuses any
missing/incomplete cell and compares the sweep with the existing 80%-retention
and unmasked reference runs (117 runs total):
   sbatch cluster/cril/tier2_feature_aggregate.sbatch

The JSON/CSV summary is written to runs/tier2_pythia/feature_sweep_analysis.
