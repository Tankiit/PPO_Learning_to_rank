# Ranking-Based Reward Models for Explanation Quality

Multi-seed experiments for the ARR resubmission. This repo reproduces all
paper tables with confidence intervals and significance tests.

---

## Quick Start

```bash
# 1. Clone and install
git clone <repo-url> && cd repo
pip install torch transformers datasets huggingface_hub scipy tqdm

# 2. Test pipeline works (< 2 minutes)
python -m src.train --dataset ds_critique --loss listnet --epochs 2 --output_dir test_run

# 3. If that works, you're ready. See your assigned tasks below.
```

## Task Assignments

Tasks are ordered by priority — complete Task 1, then Task 2, then Task 3, and finally Task 4 if time remains. If GPU time is limited, Task 1 is the most important.

### Task 1: DS-Critique Bank Experiments (NEW — reviewer response)
**Priority: CRITICAL** · **Time: ~20h on V100**

This is the non-NLI experiment that directly addresses reviewer criticism
("evaluation confined to NLI tasks"). It runs our loss comparison on science
reasoning data from the Digital Socrates Critique Bank.

```bash
bash scripts/run_ds_critique_experiments.sh
```

This trains MSE, Binary, RankNet, ApproxNDCG, ListNet × 5 seeds = 25 runs
on DS-Critique Bank, plus zero-shot transfer from NLI-trained models.

**What to check:** After it finishes, look at the separation ratios:
```bash
python -m scripts.aggregate_results --input results/multi_seed/ds_critique
```
We expect MSE sep. ratio ~0.05–0.15, ListNet ~0.80–0.95 — same pattern
as NLI, proving score compression is loss-level, not domain-specific.

**Send back:** `tar czf ds_critique_results.tar.gz results/multi_seed/ds_critique/`

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `ModuleNotFoundError: No module named 'src'` | Run from repo root: `cd /path/to/repo && python -m src.train ...` |
| `No module named 'huggingface_hub'` | `pip install huggingface_hub` |
| DS-Critique download fails | `huggingface-cli download allenai/DS_Critique_Bank --repo-type dataset --local-dir data/ds_critique_bank` |
| CUDA out of memory | Use `--batch_size 8` instead of 16 |
| NLI experiments use placeholder data | Expected — NLI loaders not wired yet. Run DS-Critique first. |
| Script says "SKIP" for everything | Previous run exists. Delete output dir to re-run: `rm -rf results/multi_seed/ds_critique/loss_comparison/listnet/seed_42` |
| Very few DS-Critique ranking groups | Some questions have few student models. Edit `min_candidates_per_query=2` in `src/data/loader_bridge.py` line ~148 |

## Key Metrics to Watch

When reviewing output, these are the numbers that matter:

- **Separation Ratio** — THE critical metric. Must be >0.8 for ListNet, <0.15 for MSE.
  This proves our core claim about score compression.
- **NDCG@5** — Ranking quality. ListNet should be >0.85, MSE <0.80.
- **Spearman ρ** — Correlation with ground truth. ListNet >0.75, MSE <0.55.

If separation ratio is high but NDCG is low, something is wrong with the
data loading. If both are low, check that the loss function is correct.
If both are high across MSE and ListNet, the data doesn't have enough
quality variation (ranking is too easy).
